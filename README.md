# 🤖 NOVA AI

NOVA AI is a professional AI chatbot built using **Python, Streamlit, LangChain, and Groq**.

It provides a simple and interactive chat interface where users can ask questions and receive AI-generated responses.

---

## 🚀 Features

- 💬 AI Chatbot
- ⚡ Streaming AI responses
- 🧠 Powered by LangChain
- 🤖 Groq LLM integration
- 💾 Conversation history
- 🔍 Search conversations
- 📌 Pin conversations
- ✏️ Rename conversations
- 🗑️ Delete conversations
- 🕒 Date and time for conversations
- 🎨 Light/Dark theme
- 📱 Responsive web interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- LangChain
- LangChain Groq
- SQLite
- Python-dotenv
